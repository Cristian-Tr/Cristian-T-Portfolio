Capitolul 1: Concepte Fundamentale

Conceptul de Enhanced HTML utilizează tehnologii web (HTML5, CSS3, JavaScript) pentru a transforma un text static într-o experiență educațională interactivă și atractivă datorită resurselor multimedia (fișiere audio-video, chestionare autoevaluabile, jocuri educaționale, diagrame dinamice), designului responsive adică adaptabil pe orice tip de dispozitiv, posibilității de acces la mii de cărți fără a le transporta, adaptării conținutului la nevoile elevilor cu deficiențe de vedere (modificare font și fundal, etc).
Spre deosebire de un fișier PDF, care reproduce o pagină clasică, formatul Enhanced HTML poate crește implicarea elevilor prin implicare și interacțiune! 💡 Acesta este un Pop-up Pedagogic! Oferă elevului definiția instant, fără a-l face să caute la sfârșitul manualului. care influențează întreaga lecție.
